# Iron Invest Group

Портал объектов недвижимости на Крите (регион Ханья, побережье Апокоронаса):
карта района и карточки объектов с фильтрами.

**Сайт:** https://lexgoart.github.io/iron-invest/

## Что это

Статический сайт без сборки и зависимостей — открывается прямо из файлов.

| Файл | Назначение |
|---|---|
| `index.html` | страница |
| `styles.css` | дизайн-система |
| `data.js` | **все объекты — правится здесь** |
| `geo.js` | география: береговая линия, рельеф, дороги, застройка (OpenStreetMap + SRTM) |
| `figure.js` | отрисовка карты |
| `app.js` | коллекция, фильтры, карточка объекта |
| `i18n.js` | тексты на трёх языках |
| `store.js` | правки через localStorage |
| `iron-invest.html` | тот же сайт одним файлом — можно открыть без интернета |

## Как добавить объект или поправить данные

Всё в `data.js`: один массив, один объект — одна запись. Цены и площади со
значением `null` показываются как «уточняется», цена — как «по запросу».

Фотографии кладутся в `photos/` под именем `<id-объекта>-01.jpg` (далее `-02`,
`-03`). Пока файла нет, на его месте стоит текстовая заглушка.

## Языки

Русский, польский, английский. Язык определяется по браузеру, выбор
запоминается. Тексты — в `i18n.js`.

## Статус

Данные предварительные: координаты приблизительные, цены и фотографии
уточняются. Поэтому сайт закрыт от поисковых систем (`robots.txt` и `noindex`).
Когда данные будут готовы — удалить `robots.txt` и строку `noindex` в
`index.html`.
