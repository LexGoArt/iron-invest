# Фотографии объектов

Положи файлы сюда — сайт подхватит их сам, править код не нужно.

## Имена файлов

Формат: `<id-объекта>-01.jpg`, `-02.jpg`, `-03.jpg` …
Первый файл (`-01`) становится главным фото (обложкой в сетке).

| Объект | Имена файлов |
|---|---|
| Amour Relax Hotel | `amour-relax-01.jpg`, `-02`, `-03` |
| Plaka 1 | `plaka-1-01.jpg` … |
| Plaka 2 | `plaka-2-01.jpg` … |
| Plaka 3 (таверна) | `plaka-3-taverna-01.jpg` … |
| Plaka 4 | `plaka-4-01.jpg` … |
| Ханья 1 (квартира) | `chania-1-apartment-01.jpg` … |
| Ханья 2 (магазин) | `chania-2-shop-01.jpg` … |
| Ханья — пригород | `chania-suburb-house-01.jpg` … |
| Eudora 1 (вилла) | `eudora-1-villa-01.jpg` … |
| Eudora 2 (участок) | `eudora-2-plot-01.jpg` … |
| Almyrida 1 | `almyrida-1-01.jpg` … |

Если файла нет — на его месте останется честный типографский плейсхолдер
«Фотографии готовятся». Ничего не ломается, битых картинок не будет.

Чтобы добавить объекту больше трёх снимков, допиши пути в `media.photos`
у нужного объекта в `data.js`.

## Требования к файлам

- Формат: JPG (или WebP), горизонтальные кадры.
- Размер: длинная сторона **2000–2400 px**, вес до ~500 КБ. Больше не нужно —
  сайт статический, каждый мегабайт замедляет открытие.
- Обложка (`-01`) кадрируется под 4:5 в сетке и 16:10 в карточке —
  главное держи по центру, не у самого края.

## ⚠️ Про права на фото

На публичный сайт можно ставить **только те снимки, права на которые есть у нас**:
съёмка по нашему заказу, фото от собственника с разрешением, или наши
собственные кадры.

**Нельзя** брать фотографии с Trip.com, Booking, Airbnb и подобных площадок —
даже если это фото нашего объекта. Там они опубликованы на условиях площадки,
часто с их водяным знаком, и их перепубликация на коммерческом сайте — нарушение.

Скриншот с Trip.com, который ты присылал, использовать в таком виде не стоит:
на нём водяной знак площадки. Нужен **оригинал** — у отеля он почти наверняка
есть (это его же рекламная аэросъёмка).
